## ABI, expressions and bindings

`void bn_evaluate(const ControllerInputs*, ControllerOutputs*)`, Microsoft x64:
RCX=input pointer, RDX=output pointer; two distinct 20-byte buffers, little-endian,
alignment 4, five consecutive `uint32_t` fields. Only canonical 0/1 inputs are
covered. Every output is written on every call. `src/controller.h` asserts both
sizes, alignments and all ten field offsets.

| Offset / input bit | Input | Accepted game port | Output at same offset | Expression |
| --- | --- | --- | --- | --- |
| 0 / 0 | crossing | crossing.occupied | crossingPower | crossing |
| 4 / 1 | liftPlate | liftPlate.occupied | liftPower | liftPlate |
| 8 / 2 | link | link.value | relayPower | link |
| 12 / 3 | maintenance | maintenance.value | firewallActive | NOT maintenance |
| 16 / 4 | exitSocket | exitSocket.occupied | exitReady | exitSocket |

`case_id = crossing | (liftPlate << 1) | (link << 2) | (maintenance << 3) | (exitSocket << 4)`.
The columns describe separate input/output buffers. All bindings are uninverted:

| Output | Binding IDs | Targets |
| --- | --- | --- |
| crossingPower | nearPower, farPower | nearAnchor.active, farAnchor.active |
| liftPower | liftPower | serviceLift.power |
| relayPower | lowerLink, upperLink | lowerRelay.power, upperRelay.power |
| firewallActive | payloadFirewallPower | payloadFirewall.active |
| exitReady | exitPower | exit.unlock |

NOT belongs in the firewall expression; do not invert its binding again. Two
anchors share crossingPower and two relay ends share relayPower: they are not
extra native outputs. **v2 output offset 12 is firewallActive; exitReady moved
to 16.** Do not use the original HANDSHAKE's four-output buffer or legacy exit
gate with this specimen. Pin the package version and PE hash alongside any address.

The game owns body/cube occupancy, cube-only PAYLOAD acceptance, reversible LINK,
one-use maintenance commitment, cargo ownership, checkpoints, respawn, movement,
grapple, lifts/relays and firewall contact handling. Native exitReady is the raw
payload unlock request; the durable exit latch and two physical arrivals remain
game-owned. Maintenance has no Boolean gate on exitReady.
